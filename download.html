⚠️ Windows says "Windows protected your PC" or blocks the app? JoeBrowser is not code-signed (open-source), so Windows SmartScreen shows a blue warning the first time you run any new .exe from the internet. Click More info → Run anyway — the app is safe and 100% open source (MIT). If Windows Defender quarantines the file, click Allow on device or add an exclusion in Windows Security → Virus & threat protection → Exclusions. Still won't open? Check %APPDATA%\JoeBrowser\logs\crash.log and tell us in the Issues tab.
First time? Download Setup → double-click → install → launch JoeBrowser. Your profiles are encrypted locally with a master password. If you want no install, use Portable – just run the .exe.

Method 1 — Direct download

Go to Releases page, pick the newest version, download Setup or Portable .exe. This is the fastest.

https://github.com/pritamsarkar711/JoeBrowser/releases

Method 2 — Build on Windows (1 cmd)

If releases are empty, build the exe yourself on Windows in 2 minutes:

git clone https://github.com/pritamsarkar711/JoeBrowser.git cd JoeBrowser npm ci npm run dist:win REM exe will be in /release/

Or double-click scripts/build-windows.bat

Method 3 — Trigger CI build

Maintainers: push a tag or run workflow manually.

git tag v1.0.2 git push origin v1.0.2 # wait 8-12 min, check Actions tab # exe appears in Releases automatically
⚙️ View CI Build Status (Windows EXE Builder) 📖 Build Docs 📦 Download Source ZIP
